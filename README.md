### 🧠 NeuralVault

A local-first AI agent harness that runs on hardware you own. Agents pick up work from a shared board on their own schedule, act on your files, and wait for approval before anything leaves the machine — and its memory is plain Markdown you can read, diff and back up, rather than a database holding your knowledge hostage. I work across the harness and its Android client: capture that never fails, a vault that syncs peer to peer with no cloud in the middle, and a fleet you can trust while you are not looking. ### 📐 How I Work

> **Silence is never a status.** A stuck job and a working job look identical from outside, so every long step states its expected duration before it starts and reports its own overruns.
>
> **A report of success is not evidence of success.** If the only proof a thing worked is the call that tried to make it work, that is an assertion — read the state back another way.
>
> **Done means done.** Nothing irreversible gets green-lit while related work is open, and every completion report says what was *not* done.

Written up in full, with the incident behind each rule, in **[claude-operating-manual](https://github.com/owenbouchie-crypto/claude-operating-manual)**.
